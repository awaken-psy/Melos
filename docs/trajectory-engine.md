# 轨迹引擎

轨迹引擎是 Melos 的核心，负责生成逼真的运动轨迹和传感器数据。

## 数据流

```
实地采集 (collector) → GPS 清洗 → 多圈中位数平均 → 外推 4m 补偿
    → TrackProfile (Catmull-Rom spline) → TrajectoryGenerator → Hook 注入
```

完整流程：

1. **实地采集**：使用采集器在目标场地上采集真实 GPS 轨迹
2. **GPS 清洗**：`RealTrackLoader` 对原始数据进行多步清洗
3. **圈检测与平均**：自动检测跑道圈数，多圈数据取中位数平均，消除单圈误差
4. **TrackProfile 构建**：将清洗后的数据构建为闭合跑道模型
5. **Catmull-Rom 插值**：生成任意距离处的精确坐标和方向
6. **动态轨迹生成**：`TrajectoryGenerator` 按时间推进，生成带有速度变化、加速限制的轨迹
7. **Hook 注入**：通过 LSPosed hook 将生成的数据注入到系统 API

## 关键模块

### RealTrackLoader

从指纹 JSON 加载并清洗真实轨迹数据，清洗流程：

```
原始 GPS 点 → accuracy 过滤 (>30m 丢弃) → spike 去除 (相邻点突变)
    → 速度过滤 (>50km/h 丢弃) → 多趟清洗 → 平滑 → 圈检测
    → 中位数平均 → TrackProfile
```

多圈中位数平均是关键步骤：同一跑道采集多圈数据后，在每个距离点上取中位数，可以有效消除 GPS 漂移和单次跑偏的影响。外推 4m 补偿确保闭合处平滑连接。

### GeoUtils

球面地理计算工具集：

| 方法 | 功能 |
|------|------|
| `haversine` | 两点间球面距离（Haversine 公式） |
| `bearing` | 两点间方位角 |
| `destination` | 从某点沿方位角移动指定距离后的坐标 |
| `offsetMeters` | 经纬度偏移指定米数后的坐标 |
| `catmullRom` | Catmull-Rom 样条插值（给定 4 个控制点和参数 t） |
| `wgs84ToGcj02` | WGS-84 坐标转 GCJ-02（国测局偏移修正） |

> GCJ-02 转换很重要：中国地图服务（高德、腾讯地图）使用 GCJ-02 坐标系，而 GPS 原始数据是 WGS-84。不转换会有约 500m 的偏移。

### TrackProfile

闭合跑道几何模型：

- 输入一组有序 GPS 点，构建为闭合环
- 使用 Catmull-Rom spline 在任意距离处插值坐标
- 计算每个插值点的切线方向（bearing），用于陀螺仪数据生成
- 支持任意总距离的跑道（400m 标准跑道、操场等）

Catmull-Rom spline 的优势：
- 经过所有控制点（不像 Bezier 曲线只逼近）
- 局部性：修改一个控制点只影响相邻区间
- C1 连续性：切线方向平滑过渡

### TrajectoryGenerator

动态轨迹生成器，模拟真实跑步行为：

- **速度变化**：基于真实 speed profile 插值，不是匀速运动
- **热身曲线**：起步阶段使用二次曲线逐渐加速，不会突然达到目标速度
- **加速限制**：加速度不超过人体极限（约 3 m/s²）
- **GPS 精度随机游走**：模拟真实 GPS 的精度波动
- **时间推进**：支持时间快进、暂停、恢复

### FingerprintDatabase

WiFi/基站指纹空间查询：

- 预先存储场地各位置的 WiFi AP 和基站数据
- KNN（K-Nearest Neighbors）算法根据当前坐标查询最近的指纹点
- 在 RSSI（信号强度）上添加随机噪声，避免每次返回完全相同的数据
- 支持多个场地数据切换

## 传感器注入架构

传感器注入独立于 GPS 运行，有自己的高频注入循环：

### 注入循环

- **频率**：50Hz 独立注入循环（非 GPS 同步），各传感器按自身采样率分频
- **SensorEvent 创建**：通过 `Unsafe.allocateInstance` 创建，兼容所有 ROM 和进程（标准反射调用 `SensorEvent(int, int)` 构造器在部分 ROM 上会崩溃）
- **Hook 覆盖**：`registerListener` 全部 4 个重载已 hook（含 Handler 参数版本）

### 各传感器数据生成

| 传感器 | 生成策略 |
|--------|---------|
| 加速度计 | 三段式波形（蹬地/腾空/落地）+ hash 白噪声，模拟真实步态 |
| 气压计 | 海拔换算 + sin 低频漂移 + hash 噪声，用于海拔验证 |
| 磁力计 | 方位角驱动地磁场 + per-axis hash 噪声 |
| 陀螺仪 | 角速度同步（与轨迹 bearing 变化率一致）+ 步频摆动 |
| 步进检测器 | 基于加速度计步态周期的峰值检测 |

### GPS 冷启动模拟

真实的 GPS 定位在启动时精度会逐渐提升。Melos 模拟这一行为：

- 前 20 秒精度因子从 5x 渐降到 1x
- 模拟卫星数从 3 渐增到 9+
- 精度随机游走，不会出现不自然的突变

这一细节很重要——如果 hook 后的 GPS 从第一秒就返回完美精度，反而会暴露异常。
